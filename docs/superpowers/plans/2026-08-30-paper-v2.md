# 논문 v2 (주장 감사 측정 논문) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** E1~E4의 측정으로 CMT/Vim 대비의 정량적 주장 여섯 개를 판정하는 영문 arXiv 프리프린트를, 모든 수치가 커밋된 CSV에서 자동 생성되는 구조로 만든다.

**Architecture:** `paper/`에 LaTeX 원고를 두고, `paper/make_tables.py`가 `results/*/`의 CSV를 읽어 `paper/generated/`에 표(`.tex`)와 매크로를 생성한다. 본문은 숫자를 직접 쓰지 않고 `\input`과 매크로로만 받는다. 그림은 기존 `figures/*.py`에 논문용 스타일 인자를 더해 같은 CSV 경로에서 PDF로 뽑는다. 테스트가 (1) 생성된 표의 값이 CSV와 일치하는지, (2) 본문에 손으로 쓴 측정 수치가 없는지를 검사한다.

**Tech Stack:** LaTeX(tectonic), Python 3.10.13 / matplotlib (고정 환경), pytest

## Global Constraints

스펙 `docs/superpowers/specs/2026-08-30-paper-v2-design.md`가 상위 문서다. 충돌하면 스펙이 우선한다.

- **모든 python·pytest는 고정 환경 래퍼를 통과한다**: `MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*' wsl bash tools/run.sh python -m pytest -q`. 래퍼가 exit 1로 죽으면 고쳐서 돌리지 말고 왜 없는지 확인한다.
- **수치를 손으로 다시 계산하지 않는다.** 논문의 모든 수치는 `results/*/`의 CSV에서 나온다. 반올림도 출처를 따른다.
- **사전 등록한 예측표는 측정 후에 고치지 않는다.** 빗나간 예측(E3 예측 1, E4 예측 4)은 빗나간 그대로 싣는다.
- **커밋 저자는 사용자 단독이다.** `Co-Authored-By: Claude`, Anthropic 트레일러, "Generated with Claude Code"를 커밋 메시지·PR 본문에 넣지 않는다.
- **커밋과 푸시는 사용자가 요청할 때만 한다.** 기본 브랜치에 있으면 먼저 브랜치를 딴다. 이 계획의 각 태스크는 커밋 단계를 포함하지만, 브랜치는 `feat/paper-v2` 하나를 쓴다.
- **저장소 문서(계획·스펙·README·HANDOFF)는 한국어로 쓴다. 논문 본문(`paper/**/*.tex`)은 영어로 쓴다.**
- **ASCII 제약**: CSV의 범주 값과 matplotlib 캔버스에 그려지는 문자열만 해당한다.
- **저장소를 public으로 전환하지 않는다.** 학회 답변 대기 중이다(스펙 "공개·게시 게이트"). 이 계획의 어떤 태스크도 저장소 공개를 수행하지 않는다.
- **새 측정을 하지 않는다.** 필요해 보이는 측정은 전부 §6 Limitations에 적고 넘어간다.
- 논문에서 인용하면 안 되는 것은 스펙 "논문에 쓰면 안 되는 것" 절에 있다. 원고를 쓰는 모든 태스크가 그 절을 지킨다.

## 파일 구조

| 파일 | 책임 |
|---|---|
| `tools/latex.sh` | LaTeX 툴체인 게이트. 없으면 exit 1 |
| `paper/main.tex` | 문서 클래스, 패키지, 저자, 섹션 `\input` |
| `paper/preamble.tex` | 패키지·매크로 정의 |
| `paper/sections/*.tex` | 섹션별 본문 (영어) |
| `paper/generated/*.tex` | 표. `make_tables.py`가 생성. 손으로 고치지 않는다 |
| `paper/generated/macros.tex` | 본문 산문에 박히는 수치의 매크로. 생성물 |
| `paper/figures/*.pdf` | 그림. `figures/*.py`가 생성. 생성물 |
| `paper/make_tables.py` | `results/*/*.csv` → `generated/` |
| `paper/make_figures.py` | `results/*/` → `paper/figures/*.pdf` |
| `paper/refs.bib` | 참고문헌 |
| `paper/numbers_allowlist.txt` | 본문에 손으로 써도 되는 숫자 (해상도, 패치 크기 등) |
| `tests/test_paper_tables.py` | 생성된 표·매크로가 CSV와 일치하는지 |
| `tests/test_paper_prose.py` | 본문에 손으로 쓴 측정 수치가 없는지 |

`paper/generated/`와 `paper/figures/`는 생성물이지만 **커밋한다** — 논문 빌드가 CSV 없이도 재현 가능해야 하고, 생성물과 CSV가 어긋나면 테스트가 잡는다.

`tools/latex.sh`:
```bash
#!/usr/bin/env bash
# 논문을 빌드한다. tools/run.sh와 같은 철학이다 - 툴체인이 없으면 죽는다.
#
# 쓰는 법 (저장소 루트에서):
#   MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*' wsl bash tools/latex.sh
#
# 조용히 다른 LaTeX으로 돌아가면 폰트·패키지 판본이 달라져 재현되지 않는다.
# tools/run.sh가 측정에 대해 하는 일을 이 스크립트가 조판에 대해 한다.
set -euo pipefail

SCRIPT_DIR=$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd -P)
REPO_ROOT=$(cd "$SCRIPT_DIR/.." && pwd -P)
cd "$REPO_ROOT/paper"

TECTONIC=""
for candidate in "$HOME/bin/tectonic" "$(command -v tectonic 2>/dev/null || true)"; do
    if [ -n "$candidate" ] && [ -x "$candidate" ]; then TECTONIC="$candidate"; break; fi
done

if [ -z "$TECTONIC" ]; then
    echo "tectonic이 없다. 설치 절차는 docs/superpowers/plans/2026-08-30-paper-v2.md Task 1을 볼 것." >&2
    exit 1
fi

exec "$TECTONIC" -X compile main.tex --keep-logs "$@"
```

`tests/test_paper_tables.py`:
```python
"""생성된 표와 매크로가 CSV와 일치하는지 검사한다.

이 테스트가 없으면 CSV가 바뀌어도 논문의 숫자가 조용히 옛 값으로 남는다.
E4 README에서 손으로 한 대조를 자동화한 것이다.
"""
import csv
from pathlib import Path

import pytest

from bench.factorial import cell_means, summarize
from paper import make_tables


@pytest.fixture(scope="module")
def generated(tmp_path_factory):
    out = tmp_path_factory.mktemp("generated")
    make_tables.build(out)
    return out


def test_build_writes_every_expected_file(generated):
    names = {p.name for p in generated.iterdir()}
    assert names == {
        "macros.tex",
        "tab_e1_sweep.tex",
        "tab_e2_erf.tex",
        "tab_e3_excess.tex",
        "tab_e4_cells.tex",
        "tab_e4_effects.tex",
    }


def test_e4_effects_table_matches_factorial_module(generated):
    rows = list(csv.DictReader(open("results/e4/runs.csv", encoding="utf-8")))
    text = (generated / "tab_e4_effects.tex").read_text(encoding="utf-8")
    for _, (mean, std) in summarize(rows).items():
        assert f"{mean * 100:+.2f}" in text
        assert f"{std * 100:.2f}" in text


def test_e4_cells_table_matches_cell_means(generated):
    rows = list(csv.DictReader(open("results/e4/runs.csv", encoding="utf-8")))
    text = (generated / "tab_e4_cells.tex").read_text(encoding="utf-8")
    for _, (mean, std) in cell_means(rows).items():
        assert f"{mean * 100:.2f}" in text
        assert f"{std * 100:.2f}" in text


def test_e1_table_carries_every_measured_row(generated):
    rows = list(csv.DictReader(open("results/e1/sweep.csv", encoding="utf-8")))
    text = (generated / "tab_e1_sweep.tex").read_text(encoding="utf-8")
    assert len(rows) == 15
    for row in rows:
        assert f"{float(row['flops_total']) / 1e9:.2f}" in text


def test_macros_carry_the_headline_numbers(generated):
    text = (generated / "macros.tex").read_text(encoding="utf-8")
    for name in ("StructureEffect", "InteractionEffect", "VimAngleRandom",
                 "VimTallWideZ", "CmtParamsHigh", "HoursTotal"):
        assert f"\\newcommand{{\\{name}}}" in text


def test_macro_values_come_from_the_csv(generated):
    rows = list(csv.DictReader(open("results/e4/runs.csv", encoding="utf-8")))
    structure_mean, _ = summarize(rows)["structure"]
    text = (generated / "macros.tex").read_text(encoding="utf-8")
    assert f"\\newcommand{{\\StructureEffect}}{{{structure_mean * 100:.2f}}}" in text


def test_stale_generated_files_are_removed(generated):
    stray = generated / "tab_obsolete.tex"
    stray.write_text("stale", encoding="utf-8")
    make_tables.build(generated)
    assert not stray.exists()
```

`paper/__init__.py`는 빈 파일로 만든다.

`paper/make_tables.py`:
```python
"""results/*/의 CSV에서 논문의 표와 매크로를 생성한다.

논문에 손으로 옮겨 적은 숫자가 남지 않게 하는 장치다. 본문은 여기서 나온
\\input과 매크로로만 수치를 받는다.

효과값은 bench.factorial의 함수를 그대로 부른다 - 논문과 저장소가 같은 계산을
쓰게 하려는 것이다. 여기서 다시 계산하면 두 값이 갈라질 수 있다.
"""
import csv
from pathlib import Path

from bench.factorial import CELLS, cell_means, summarize

RESULTS = Path("results")
CELL_LABEL = {
    "a_deit_ti": "A DeiT-Ti (flat, attn)",
    "b_vim_ti": "B Vim-Ti (flat, SSM)",
    "c_cmt_ti": "C CMT-Ti (hier, attn)",
    "d_hvim": "D H-Vim (hier, SSM)",
}
EFFECT_LABEL = {
    "structure": r"Structure $(C{+}D)/2-(A{+}B)/2$",
    "operator": r"Operator $(A{+}C)/2-(B{+}D)/2$",
    "interaction": r"Interaction $(D{-}B)-(C{-}A)$",
}
AREA_BINS = ("<2%", "2-5%", "5-10%", "10-20%", "20-40%", ">=40%")
MODELS = ("deit_s", "cmt_s", "vim_s")


def _read(path):
    with Path(path).open(encoding="utf-8") as handle:
        return list(csv.DictReader(handle))


def _e1_rows():
    return _read(RESULTS / "e1" / "sweep.csv")


def _e4_rows():
    return _read(RESULTS / "e4" / "runs.csv")


def _e2_rows(n_images="512"):
    return [r for r in _read(RESULTS / "e2" / "erf_metrics.csv")
            if r["n_images"] == n_images]


def _e3_rows():
    return [r for r in _read(RESULTS / "e3" / "coverage.csv")
            if r["status"] == "ok"]


def _table(caption, label, colspec, header, body_rows):
    lines = [r"\begin{table}[t]", r"\centering",
             rf"\caption{{{caption}}}", rf"\label{{{label}}}",
             rf"\begin{{tabular}}{{{colspec}}}", r"\toprule", header + r" \\",
             r"\midrule"]
    lines += [row + r" \\" for row in body_rows]
    lines += [r"\bottomrule", r"\end{tabular}", r"\end{table}"]
    return "\n".join(lines) + "\n"


def tab_e1_sweep():
    body = []
    for row in _e1_rows():
        ips = row["images_per_sec"]
        ips_text = f"{float(ips):.1f}" if ips else r"\textemdash"
        body.append(" & ".join([
            row["model"].replace("_", r"\_"),
            row["resolution"],
            f"{float(row['params']) / 1e6:.2f}",
            f"{float(row['flops_total']) / 1e9:.2f}",
            f"{float(row['latency_ms']):.2f}",
            f"{float(row['peak_allocated_bytes']) / 2 ** 20:.1f}",
            ips_text,
        ]))
    return _table(
        "Measured resolution sweep. Throughput is empty where the "
        "throughput search hit CUDA OOM; the reason is recorded in the "
        "\\texttt{error} column of \\texttt{results/e1/sweep.csv}.",
        "tab:e1", "llrrrrr",
        "Model & Res. & Params (M) & FLOPs (G) & Latency (ms) & "
        "Peak alloc (MiB) & img/s", body)


def tab_e2_erf():
    body = []
    for row in _e2_rows():
        if row["condition"] not in ("natural", "random_init"):
            continue
        body.append(" & ".join([
            row["model"].replace("_", r"\_"),
            row["condition"].replace("_", r"\_"),
            f"{float(row['anisotropy']):.3f}",
            f"{float(row['principal_angle_deg']):.2f}",
            f"{float(row['decay_ratio']):.3f}",
        ]))
    return _table(
        "ERF anisotropy at $n=512$ images. The covariance index separates "
        "no model; the axis-wise decay ratio and the untrained condition do.",
        "tab:e2", "llrrr",
        "Model & Condition & Anisotropy & Principal angle (deg) & Decay ratio",
        body)


def tab_e3_excess():
    rows = _e3_rows()
    body = []
    for area_bin in AREA_BINS:
        cells = []
        for model in MODELS:
            values = [float(r["precision_at_k"]) - float(r["random_baseline"])
                      for r in rows
                      if r["model"] == model and r["condition"] == "pretrained"
                      and r["area_bin"] == area_bin]
            cells.append(f"{sum(values) / len(values):.4f}" if values
                         else r"\textemdash")
        body.append(" & ".join([area_bin.replace("%", r"\%"), *cells]))
    return _table(
        "Above-baseline precision@K by object area, pretrained weights. "
        "Vim-S is the lowest in every bin.",
        "tab:e3", "lrrr",
        "Area bin & DeiT-S & CMT-S & Vim-S", body)


def tab_e4_cells():
    means = cell_means(_e4_rows())
    body = [" & ".join([CELL_LABEL[cell],
                        f"{means[cell][0] * 100:.2f}",
                        f"{means[cell][1] * 100:.2f}"]) for cell in CELLS]
    return _table(
        "E4 cell means, Tiny-ImageNet top-1 (\\%), $n=3$ seeds.",
        "tab:e4cells", "lrr", r"Cell & Top-1 & Std", body)


def tab_e4_effects():

                 and r["aspect_class"] == aspect]
        for aspect in ("tall", "wide")

                   + statistics.variance(wide) / len(wide))
```

```python
측정처럼 보이는 수치만 잡는다: 소수점 두 자리 이상, 또는 퍼센트가 붙은 수.

import re
from pathlib import Path

import pytest

SECTIONS = Path("paper/sections")
ALLOWLIST = Path("paper/numbers_allowlist.txt")

# 소수점 두 자리 이상, 또는 숫자 뒤 퍼센트.
SUSPECT = re.compile(r"\d+\.\d{2,}|\d+(?:\.\d+)?\s*\\?%")
# LaTeX 주석은 조판되지 않으므로 검사 대상이 아니다.
COMMENT = re.compile(r"(?<!\\)%.*$")


def _allowed():
    if not ALLOWLIST.exists():
        return set()
    return {line.split("#")[0].strip()
            for line in ALLOWLIST.read_text(encoding="utf-8").splitlines()
            if line.split("#")[0].strip()}


def _section_files():
    return sorted(SECTIONS.glob("*.tex"))


def test_sections_directory_exists():
    assert SECTIONS.is_dir(), "paper/sections/ 가 없다"


@pytest.mark.parametrize("path", _section_files(), ids=lambda p: p.name)
def test_no_hand_written_measurements(path):
    allowed = _allowed()
    offenders = []
    for lineno, raw in enumerate(path.read_text(encoding="utf-8").splitlines(), 1):
        line = COMMENT.sub("", raw)
        for match in SUSPECT.finditer(line):
            token = match.group(0).strip()
            if token not in allowed:
                offenders.append(f"{path}:{lineno}: {token!r}")
    assert not offenders, (
        "본문에 손으로 쓴 측정 수치가 있다. paper/generated/macros.tex의 "
        "매크로를 쓰거나, 측정값이 아니라면 paper/numbers_allowlist.txt에 "
        "이유와 함께 추가할 것:\n" + "\n".join(offenders))


def test_allowlist_entries_carry_a_reason():
    if not ALLOWLIST.exists():
        return
    for lineno, line in enumerate(
            ALLOWLIST.read_text(encoding="utf-8").splitlines(), 1):
        if not line.strip() or line.lstrip().startswith("#"):
            continue
        assert "#" in line, (
            f"{ALLOWLIST}:{lineno}: allowlist 항목에는 이유를 적는다 "
            f"(`값  # 이유`). 이유 없는 예외는 규칙을 조용히 비운다.")


def test_the_checker_actually_catches_a_planted_number(tmp_path):

    planted.write_text("Structure dominates by 6.94 points.\n", encoding="utf-8")
```
